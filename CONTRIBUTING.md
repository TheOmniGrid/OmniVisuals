# Contributing to OmniVisuals documentation

This public repository accepts documentation corrections, consumer-facing
feature requests and reproducible gaming compatibility reports.

Before opening an issue:

1. Confirm that genuine OmniShade 1.0.0 or newer is installed and working.
2. Reproduce with a maintained OmniVisuals profile before testing custom edits.
3. Remove usernames, personal paths, account data and private delivery links.
4. Do not upload shaders, textures, presets, installers, archives or private
   product files.

OmniVisuals remains a shader-only consumer suite. Requests for DLLs, injection,
developer consoles, capture systems, telemetry, calibration laboratories or
shader-analysis surfaces are outside the public consumer scope.

Documentation changes should preserve the existing concise style, honest
screen-space limitations and the distinction between OmniShade and
OmniVisuals.
