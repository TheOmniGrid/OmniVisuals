# Security policy

Please do not disclose a suspected security issue in a public GitHub issue.

Report it privately to **[omnivex@theomnigrid.biz](mailto:omnivex@theomnigrid.biz)**
with:

- the affected OmniShade and OmniVisuals versions;
- the game, graphics API and operating-system version;
- clear reproduction steps and expected impact;
- sanitized logs or screenshots when needed.

Do not attach OmniVisuals shaders, presets, installer files, private download
links, credentials or personal information. Reports are handled on a
best-effort basis.
