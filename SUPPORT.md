# Support

## Before reporting an effect problem

1. Verify that OmniShade is installed and working.
2. Verify the active preset contains OmniVisuals techniques.
3. Confirm depth-buffer selection before testing depth-driven effects.
4. Enable one motion provider and one anti-aliasing path.
5. Test the Balanced or Performance profile before custom tuning.

## Useful report contents

- OmniShade and OmniVisuals versions.
- Game, renderer, resolution, HDR mode and GPU.
- Active profile and enabled OmniVisuals shaders.
- A before/after screenshot from the same frame when possible.
- Relevant log lines and reproduction steps.

Remove usernames, personal paths and account information before posting files publicly.
